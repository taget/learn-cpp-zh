# 初中 C++ 辅导技能

这个仓库提供一个 Cursor 技能，用来辅导中国初中生学习 C++。学生几乎可以没有编程基础。

## 技能在哪

`.cursor/skills/learn-cpp-zh/`

入口是 `SKILL.md`。每一课的中文笔记在 `lessons/` 里，按文件名顺序上课。

## 在 Cursor 里怎么用

在对话里说明要辅导初中生学 C++，或点名使用技能 `learn-cpp-zh`。例如：「用 learn-cpp-zh 从第一课开始教我。」

技能一旦被调用，辅导回复都使用简体中文。程序代码保持 C++，关键字用中文解释。

## 课程顺序

课题顺序与 [Learn C++](https://github.com/Codecademy/learn-cpp) 的八个单元一致：从 Hello World 到引用与指针，后面有一个选学的井字棋挑战。这里的课笔记是原创中文，不收录该仓库里的习题原文。

## 本地查看

这不是网站。用编辑器打开 `.cursor/skills/learn-cpp-zh/SKILL.md` 即可阅读。
