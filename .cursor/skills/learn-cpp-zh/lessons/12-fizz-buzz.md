一次只讲这个步骤。大纲里的名字是 Fizz Buzz：顺着数，遇到 3 的倍数说一个词，遇到 5 的倍数说另一个词，同时是两者的倍数说第三个词。下面换成我们自己的口号。

## 步骤 1：一个数可能同时属于两档

从 1 数到 20。能被 3 整除就说「拍手」，能被 5 整除就说「跺脚」。两个都能整除时，必须先判断，否则会被前面的单档抢走。

类比：既是课代表又是体育委员的人，点名时要先喊完整头衔，不能只喊其中一个。

```cpp
#include <iostream>

int main() {
  for (int n = 1; n <= 20; n++) {
    if (n % 3 == 0 && n % 5 == 0) {
      std::cout << n << " 加油\n";
    } else if (n % 3 == 0) {
      std::cout << n << " 拍手\n";
    } else if (n % 5 == 0) {
      std::cout << n << " 跺脚\n";
    } else {
      std::cout << n << "\n";
    }
  }
  return 0;
}
```

```bash
g++ count.cpp -o count
./count
```

15 会是「加油」，3 是「拍手」，5 是「跺脚」，1 只是数字。

练习：把循环改到 30。先在纸上写出 30 应该印什么，再运行核对。
