## 步骤 1：用字符搭图案

图案不是图片文件。它是很多行文字，用 `#`、空格和字母拼出来。程序只负责把这些行打印出来。

类比：像用便利贴在教室窗户上贴出一个大字，每一行贴多长，打印就要写多长。

```cpp
#include <iostream>

int main() {
  std::cout << "#####\n";
  std::cout << "#   #\n";
  std::cout << "#   #\n";
  std::cout << "#####\n";
  return 0;
}
```

```bash
g++ block.cpp -o block
./block
```

会看到一个方框。引号里有几个空格，方框里面就有多宽。

练习：用至少四行 `std::cout`，拼出你姓氏拼音的首字母。先在纸上画好，再抄进引号。

## 讲完就停

学生只写出一个小字母就算过关。不要替他画完整个名字。
